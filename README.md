# EvolvePatcher

Клиентский патчер (ASI-плагин) для сервера **Evolve RolePlay** (SAMP 0.3.7 R1).
Отключает навязанные клиентом фичи и возвращает классический вид игры.

## Установка

1. Скопировать `!EvolvePatcher.asi` в папку с игрой (`EvolveRolePlay\packs\Default\`)
2. Рядом появятся `!EvolvePatcher.cfg` (настройки) и `!EvolvePatcher.log` (лог)
3. Запустить лаунчер как обычно

## Настройки

В файле `!EvolvePatcher.cfg` каждая опция включается/выключается значением `1`/`0` (после изменения нужен перезаход в игру):

| Опция | Описание |
|---|---|
| `no_evolve_render` | Отключает кастомный HUD Evolve (оверлей на ImGui), патчер рисует лёгкий логотип текстдравами |
| `no_custom_radar` | Отключает кастомный радар клиента, стандартный радар GTA |
| `no_esc_transparency` | Убирает полупрозрачную подложку ESC-меню |
| `no_discord_activity` | Отключает Discord Rich Presence |
| `no_new_auth` | Классическая авторизация через диалоги сампа вместо новой формы клиента |
| `no_new_spawnscreen` | Выбор спавна простым диалогом сампа вместо спавн-скрина клиента |
| `no_voice_chat` | Отключает оверлей войс-чата клиента |
| `no_framerate_vigilante` | Стандартное поведение frame limiter вместо правки клиента |
| `no_small_icons` | Нормальный размер иконок на радаре |
| `fix_aim_movement` | Фикс движения при прицеливании (samp.dll) |
| `no_binds` | Отключение биндов клиента (на актуальной версии клиента пока не находит цель) |
| `no_custom_menu` | Зарезервировано |
| `evolve_processing` | Имя модуля клиента (`__EvolveClient.asi`), служебное |

## Встроенное

- **Автопромокод**: при регистрации диалог промокода/пригласившего игрока отвечается автоматически (код задан константой `PROMOCODE` в `Plugin/autopromo.cpp`) и не появляется на экране
- **Свои текстуры эффектов**: можно класть `effectspc.txd`, `effects.fxp`, `particle.txd` в `models\`
- Сообщение в чат через 5 секунд после загрузки плагина

## Сборка

Visual Studio 2026 (toolset v145) или новее, конфигурация `Release | x86`:

```
MSBuild.exe !EvolvePatcher.sln /p:Configuration=Release /p:Platform=x86
```

Результат: `out\!EvolvePatcher.asi`.

## Диагностика

`!EvolvePatcher.log` рядом с asi: видно, какие патчи применились (`patched ...`),
какие нет (`skip ...`), адреса совпадений, база и размер модуля клиента,
а также все показываемые диалоги (`dialog show: ...`).

## Дисклеймер

Проект выложен как есть, в ознакомительных целях. Используя его, вы действуете
на свой страх и риск и принимаете правила сервера, на котором играете.
