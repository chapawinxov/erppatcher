EvolvePatcher для лаунчера
Описание функций:

* no_evolve_render — отключение кастомного рендера интерфейса Evolve и возврат старого логотипа.
* no_esc_transparency — убирает прозрачность меню паузы (ESC). Меню становится обычным и непрозрачным, что заодно открывает нормальный доступ к настройкам.
* no_binds — отключает бинды клавиш лаунчера, чтобы они не конфликтовали с игровыми клавишами и чатом.
* no_framerate_vigilante — выключает встроенный Framerate Vigilante лаунчера для комфортной игры. (Примечание: если вы всегда играли с Framerate Vigilante, не выключайте его в конфиге, а просто закиньте плагин в сборку лаунчера).
* fix_aim_movement — фиксит баги, связанные с мувментом на лаунчере.
* no_custom_radar — отключает кастомный радар лаунчера и возвращает стандартную миникарту GTA.
* no_discord_activity — отключает кастомную активность Discord: теперь в профиле отображается обычная «GTA: San Andreas», а не Evolve RP.
* no_new_auth — отключает новую авторизацию лаунчера и возвращает старое окно входа.
* no_new_spawnscreen — отключает новое окно выбора спавна, заменяя его на диалоговое.
* no_small_icons — возвращает иконки радара нормального (старого) размера вместо уменьшенных лаунчерных.
* no_voice_chat — отключает настройку микрофона в лаунчере через F2.
* Вырезана проверка сервера — теперь можно заходить на любой SA-MP сервер.
* Также внесены мелкие доработки и фиксы багов для комфортного геймплея.

Примечания по совместимости:
Для стабильной работы патчера в настройках лаунчера стоит отключить все галочки, кроме:

* Кастомных NameTags
* Прозрачного чата
* Звуков в свёрнутом режиме
* Исправленной физики машин

Остальные функции лаунчера использовать не рекомендуется.

⚠️ После обновлений лаунчера могут возникать ошибки и проблемы с патчером, которые будут исправляться в кратчайшие сроки. Актуальная версия патчера всегда доступна в этом ТГ-канале.
